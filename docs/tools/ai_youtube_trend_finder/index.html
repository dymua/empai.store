AI YouTube Trend Finder

AI YouTube Trend Finder Based on Niche — це високоякісний n8n-воркфлоу, розроблений для професійних контент-кріейторів і маркетологів, що прагнуть виявити найактуальніші теми в обраній ніші. Застосовуючи офіційні YouTube Data API та передові моделі штучного інтелекту, він аналізує відео за останні 48 годин, щоб надати глибокі інсайти щодо популярності та залученості аудиторії.

Ключові компоненти та технології

Вхідні дані та тригери

  • chat_message_received: отримання запиту від користувача;
  • інтерактивний діалог для уточнення ніші (якщо не вказана).

AI-агент (GPT-модель)

  • формує релевантні пошукові запити;
  • обробляє відповіді YouTube API та виділяє основні теми, теги й метрики (перегляди, лайки, коментарі).

Запити до YouTube

  • пошук відео за ключовими словами, опублікованих протягом останніх двох діб;
  • вибірка базових даних (ID, дата публікації, релевантність).

Отримання детальної інформації

  • Video Snippet: заголовок, опис, теги;
  • Video Statistics: кількість переглядів, лайків, коментарів;
  • Content Details: тривалість (аналітика тільки для відео довжиною від 3:30 хв).

Обробка та аналіз

  • очищення й нормалізація метаданих;
  • виявлення повторюваних тем і трендів серед вибірки;
  • складання зведеного звіту з ключовими показниками.

Використання та користь

  • Самостійний аналіз ніш — швидко отримуйте список найгарячіших тем;
  • Дослідження для клієнтів — надавайте data-driven рекомендації з контент-плану;
  • Інспірація для створення матеріалів — тренди як основа для власних відео;
  • SEO-оптимізація — підбір ключових слів і тегів із високим потенціалом залучення.

Інтеграційні можливості

  • Месенджери: Telegram, Facebook Messenger тощо для миттєвих звітів;
  • Автоматична генерація контенту: зв’язка з AI-моделями для створення сценаріїв і описів;
  • CRM і Project-менеджмент: відправка результатів аналізу в Slack, Notion, Trello.

Чому обирають саме цей воркфлоу

  • реалізовано за кращими практиками роботи з YouTube Data API й AI-аналітикою;
  • протестований на сотнях ніше­вих запитів і забезпечує стабільну точність;
  • побудований на перевірених технологіях n8n і GPT-моделях від OpenAI;
  • прозора обробка даних, збереження конфіденційності API-ключів і гарантія швидких оновлень.
